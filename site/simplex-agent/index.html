Simplicio Agent

Trabalho que deixa um rastro verificável.

Um agente para executar tarefas de engenharia e marketing dentro de um ciclo governado: entender o contexto, agir dentro de limites, verificar o resultado e registrar o que aconteceu.

Como o ciclo funciona

  • discover
  • understand
  • decide
  • act
  • verify
  • correct
  • record
  • repeat

O agente não substitui o sistema de lifecycle: os stages, leases, budgets, fila e completion pertencem ao Loop core. O marketing package fornece overlays, adapters e gates compatíveis.

O que existe neste repositório

Provider-agnostic

LLM, imagem, vídeo, analytics e publicação são resolvidos por interfaces e matriz de providers, mantendo a lógica de negócio desacoplada.

Evidência antes da afirmação

Claims, QA, tracking e relatórios passam por gates. Dados não observados permanecem nulos e recebem um motivo.

Dry-run por padrão

O caminho seguro não envia, publica ou gasta sem credenciais, policy, tracking e autoridade explícitos.

Receipts auditáveis

Manifests HBI e streams HBP preservam decisões, status, custos, falhas, deduplicação e retomadas.

Uma chamada local

npm install
DRY_RUN=true node bin/marketing-engine.mjs doctor
DRY_RUN=true node bin/marketing-engine.mjs low-ticket plan \
  --campaign-id camp-001 \
  --objective "validar uma oferta" \
  --market "software B2B" \
  --budget 100

O plano é produzido localmente, com gates explícitos. Uma saída de planejamento não é prova de demanda, receita, conversão ou lucro.
